# QRKot — благотворительный фонд поддержки котиков

Асинхронное API-приложение для фонда QRKot. Фонд собирает пожертвования
на целевые проекты, связанные с поддержкой кошачьей популяции: корм,
медицинское обслуживание, обустройство приютов и другую помощь котикам.

Новое в этой версии: отчёт по закрытым проектам в формате Excel
формируется и загружается на Яндекс Диск, а API возвращает публичную
ссылку на файл. Отчёт помогает волонтёрам видеть, какие проекты
закрываются быстрее всего.

## Как это работает

- В фонде может быть открыто несколько **целевых проектов**, у каждого —
  название, описание и требуемая сумма. Когда сумма собрана, проект
  автоматически закрывается.
- **Пожертвования** поступают в фонд, а не в конкретный проект. Каждое
  пожертвование автоматически инвестируется в самый «старый» открытый
  проект. Если пожертвование больше, чем нужно проекту, — остаток
  переходит в следующий открытый проект или ждёт создания нового.
- При создании нового проекта все свободные (нераспределённые)
  пожертвования сразу инвестируются в него.
- **Пользователи** регистрируются и аутентифицируются по JWT-токену
  (библиотека FastAPI Users). Пожертвования персонализированы: чтобы
  внести пожертвование, нужно войти в систему.
- **Отчёт на Яндекс Диске**: суперпользователь может запросить отчёт —
  приложение выберет закрытые проекты, отсортирует их по скорости сбора
  средств, сформирует Excel-файл (xlsxwriter), загрузит его в папку
  `QRKot Reports` на Яндекс Диске (httpx + REST API Диска), опубликует
  и вернёт публичную ссылку.

## Права доступа

| Роль                                                      | Возможности                                                                                                                                                                                      |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Аноним                                                  | Просмотр списка проектов, регистрация                                                                                                                                      |
| Зарегистрированный пользователь | + пожертвования и просмотр списка своих пожертвований                                                                                                         |
| Суперпользователь                            | + создание/редактирование/удаление проектов, просмотр всех пожертвований, формирование отчёта на Яндекс Диске |

Никому не разрешено: удалять пользователей, редактировать или удалять
пожертвования, редактировать или удалять закрытые проекты, удалять
проекты с внесёнными средствами, менять даты создания и закрытия
проектов.

## Технологии

- Python 3.10+ (проверено на 3.12)
- FastAPI, Pydantic v2, FastAPI Users
- SQLAlchemy 2.0 (asyncio) + aiosqlite
- Alembic
- httpx — асинхронные запросы к API Яндекс Диска
- xlsxwriter — генерация Excel-отчёта

## Запуск проекта

Клонируйте репозиторий и перейдите в него:

```bash
git clone https://github.com/0legRogovenko/QRkot-spreadsheets
cd QRkot-spreadsheets-main
```

Создайте и активируйте виртуальное окружение, установите зависимости:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Создайте файл `.env` по образцу `.env.example` и укажите OAuth-токен
Яндекс Диска (получить можно на
[Полигоне Яндекс Диска](https://yandex.ru/dev/disk/poligon/)):

```
DATABASE_URL=sqlite+aiosqlite:///./qrkot.db
SECRET=YOUR_SECRET_KEY
YANDEX_DISK_TOKEN=YOUR_YANDEX_DISK_OAUTH_TOKEN
```

Без токена приложение работает, но эндпоинт отчёта вернёт ошибку 503.

Примените миграции и запустите приложение:

```bash
alembic upgrade head
uvicorn app.main:app --reload
```

Документация API будет доступна по адресам:

- [Swagger UI](http://127.0.0.1:8000/docs)
- [ReDoc](http://127.0.0.1:8000/redoc)

## Основные эндпоинты

| Метод | Путь                          | Доступ             | Описание                                                                                                           |
| ---------- | --------------------------------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| GET        | `/charity_project/`             | все                   | Список всех целевых проектов                                                                      |
| POST       | `/charity_project/`             | суперюзер       | Создать целевой проект                                                                                 |
| PATCH      | `/charity_project/{project_id}` | суперюзер       | Редактировать проект (закрытый проект менять нельзя)                          |
| DELETE     | `/charity_project/{project_id}` | суперюзер       | Удалить проект (только без внесённых средств)                                        |
| GET        | `/donation/`                    | суперюзер       | Список всех пожертвований                                                                           |
| POST       | `/donation/`                    | пользователь | Сделать пожертвование                                                                                  |
| GET        | `/donation/my`                  | пользователь | Список своих пожертвований                                                                         |
| POST       | `/yandex/`                      | суперюзер       | Сформировать Excel-отчёт на Яндекс Диске и получить публичную ссылку |
| POST       | `/auth/register`                | все                   | Регистрация                                                                                                     |
| POST       | `/auth/jwt/login`               | все                   | Получение JWT-токена                                                                                        |

## Отчёт на Яндекс Диске

`POST /yandex/` формирует таблицу с колонками «Название проекта»,
«Время сбора» и «Описание». Проекты отсортированы по скорости сбора
средств — от самых быстрых к самым медленным. Последняя строка отчёта —
итог с общим количеством закрытых проектов. Если закрытых проектов ещё
нет, формируется пустой отчёт с датой.

Возможные ответы:

- `200` — публичная ссылка на Excel-файл;
- `503` — не задан токен Яндекс Диска;
- `500` — данные не помещаются в таблицу.

## Структура проекта

```
app/
├── api/                  # роутеры, эндпоинты, валидаторы запросов
│   └── endpoints/
│       └── yandex_api.py # эндпоинт отчёта на Яндекс Диске
├── core/                 # настройки приложения, БД и пользователей
│   └── yandex_client.py  # асинхронный клиент API Яндекс Диска
├── crud/                 # операции с базой данных
├── models/               # ORM-модели (CharityProject, Donation, User)
├── schemas/              # Pydantic-схемы запросов и ответов
├── services/             # бизнес-логика
│   ├── investment.py     # инвестирование пожертвований
│   └── yandex_api.py     # формирование Excel-отчёта
├── routers.py            # главный роутер приложения
└── main.py               # точка входа приложения
alembic/                  # миграции базы данных
```
