# QRKot — благотворительный фонд поддержки котиков

Асинхронный сервис на FastAPI для сбора пожертвований в целевые проекты
фонда. Пожертвования автоматически распределяются по открытым проектам
по принципу «первым пришёл — первым инвестируется».

Новое в этой версии: формирование отчёта по закрытым проектам в формате
Excel и загрузка его на Яндекс Диск с публикацией по публичной ссылке.

## Возможности

- Управление целевыми проектами (создание, редактирование, удаление —
  только для суперпользователей).
- Приём пожертвований от зарегистрированных пользователей.
- Автоматическое «инвестирование» пожертвований в открытые проекты.
- Регистрация и аутентификация пользователей (JWT).
- Отчёт в Excel на Яндекс Диске: закрытые проекты, отсортированные
  по скорости сбора средств, с итоговой строкой по количеству проектов.

## Технологии

- Python 3.12
- FastAPI, FastAPI Users
- SQLAlchemy (async) + aiosqlite, Alembic
- httpx — асинхронные запросы к API Яндекс Диска
- xlsxwriter — генерация Excel-файла

## Запуск проекта

1. Клонируйте репозиторий и перейдите в него:

   ```bash
   git clone <URL репозитория>
   cd QRkot_spreadsheets
   ```

2. Создайте и активируйте виртуальное окружение, установите зависимости:

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` по образцу `.env.example` и укажите OAuth-токен
   Яндекс Диска (получить можно на https://yandex.ru/dev/disk/poligon/):

   ```
   DATABASE_URL=sqlite+aiosqlite:///./qrkot.db
   SECRET=YOUR_SECRET_KEY
   YANDEX_DISK_TOKEN=YOUR_YANDEX_DISK_OAUTH_TOKEN
   ```

4. Примените миграции и запустите приложение:

   ```bash
   alembic upgrade head
   uvicorn app.main:app --reload
   ```

Документация API: http://127.0.0.1:8000/docs

## Отчёт на Яндекс Диске

`POST /yandex/` (только для суперпользователей) — формирует Excel-отчёт
по закрытым проектам, загружает его в папку `QRKot Reports` на Яндекс
Диске и возвращает публичную ссылку на файл.
